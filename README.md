# Next — Mening keyingi sevgim

Kamera ustida animatsiyali chiziq va oltita tasodifiy tanlov. Oddiy HTML, CSS va JavaScript; build kerak emas.

## GitHub Pages
Ushbu papkadagi index.html, style.css, app.js va .nojekyll fayllarini repozitoriy ildiziga yuklang. Settings → Pages → Deploy from a branch → main → / (root) → Save.

Kamera HTTPS yoki localhost orqali ishlaydi. Kamerasiz sinov ham mavjud. Video yozib olinmaydi va serverga yuborilmaydi. Shrift Google Fonts orqali yuklanadi; internet bo‘lmasa tizim shriftlari ishlaydi.

Yosh: 10–100. Bo‘y: 100–300 sm. 10 kasb, 18 xarakter, 2 jins va 12 sevimli mashg‘ulot. Barcha tanlovlar bir-biridan mustaqil, ko‘ngilochar maqsadda tasodifiy tanlanadi.
